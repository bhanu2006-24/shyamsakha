# Image & Sprite Assets Directory

Place your custom 2D sprites, textures, and illustrations here:

### Recommended Image Files:
- `krishna_sprite.png` - Custom sprite sheet or avatar for Shree Krishna.
- `balram_sprite.png` - Custom sprite sheet or avatar for Dau Balaram.
- `sakha_sprites.png` - Sprites for Sudama, Subala, Madhumangala, Mansukha.
- `cows.png` - Gau Mata sprites.
- `volleyball.png` - Custom painted volleyball / Kanduka ball.
- `kadamba_tree.png` - Lush Kadamba tree art.
- `tileset_vrindavan.png` - Ground tiles (grass, river sand, lotus water).

The game currently renders procedural high-performance 2D vector art on HTML5 Canvas, but is modularized so you can plug in sprite sheets easily!
